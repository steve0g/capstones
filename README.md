# Capstones — Blockchain Security Journey

Personal projects combining concepts learned in the Solidity Smart Contract Development course (Cyfrin Updraft), built from requirements specs without looking at a solution, to consolidate my understanding.

## Projects

- **01-gestion-stock-simplestorage** — Stock management contract (Korbanas/Fluxinnov) combining struct, array, mapping, storage/memory/calldata, functions, visibility, for loops. Deployed on Sepolia testnet. Based on Simple Storage section concepts.

- **02-bookstore** — Book inventory contract with owner-restricted add/mark-unavailable and public price lookup / availability count. Written independently to practice struct/array/access control without a cahier des charges.

- **03-phonestore** — Phone inventory contract, same pattern as bookstore (owner-restricted add/mark-sold, public price lookup). Second independent practice run.

- **04-inventory** — Generic product inventory contract, same struct/array/access control pattern applied to a third, more abstract domain. Third independent practice run.
